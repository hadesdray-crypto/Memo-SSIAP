# Date de fin de chaque version
- Chaque APK est fabriquée avec une date de fin (90 jours après la fabrication, voir android.yml). Le site web n'a pas de date de fin (LIC_FIN = 0).
- Compteur local : temps de confiance qui ne recule jamais ; un recul de la date du téléphone ajoute un jour de pénalité.
- À la fin : jeu et outils bloqués ; fiches, conduites à tenir, numéros d'urgence, mise à jour et textes légaux restent accessibles.
- Pour continuer : publier une nouvelle version (nouvelle APK, nouvelle date). Elle s'installe par-dessus l'ancienne.
